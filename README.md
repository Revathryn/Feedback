# Product Status
Revathryn is currently in active development.

Feedback, bug reports, and feature requests are reviewed regularly and used to help prioritize future releases.

# Revathryn Feedback

Welcome to the official feedback repository for Revathryn.

This repository is the central place to:

- Report bugs
- Request new features
- Suggest improvements
- Ask product-related questions
- Track known issues and planned enhancements

## Before Creating an Issue

Please take a moment to:

- Search existing issues to avoid duplicates.
- Use the appropriate issue template.
- Provide as much detail as possible.


## Reporting a Bug

When reporting a bug, please include:

- What you were trying to do
- What happened
- What you expected to happen
- Steps to reproduce the issue
- Screenshots or error messages (if available)
- Browser, operating system, and version information


## Requesting a Feature

Feature requests are welcome.

Helpful information includes:

- The problem you're trying to solve
- Your proposed solution
- Alternative approaches you've considered
- Any examples from other products
- Security Issues

Please do not report security vulnerabilities through public issues.

If you discover a security issue, contact us directly.

# Code Repository
